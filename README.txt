COS 106 LAB - STUDENT PORTFOLIO AND ACADEMIC MANAGEMENT WEBSITE

PROJECT CONTENTS
- index.html       Homepage
- about.html       About Me page
- projects.html    Projects page
- planner.html     Interactive Academic Planner
- contact.html     Contact form with JavaScript validation
- css/style.css   External responsive stylesheet
- js/main.js      Shared navigation and footer year
- js/planner.js   Add, complete, delete and save tasks
- js/contact.js   Contact form validation
- images/         Local SVG illustrations

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted cos106_student_portfolio folder in Visual Studio Code.
3. Open index.html in a browser. You can also use the VS Code Live Server extension.
4. Use the navigation menu to visit all five pages.

BEFORE SUBMISSION - PERSONALISE YOUR WORK
1. Confirm your name, institution, programme/course and academic information.
2. Replace images/profile-placeholder.svg with your own photograph (keep the filename or update the image path in index.html).
3. Replace the sample project descriptions with projects you have actually built. Add your screenshots and working links.
4. Replace the sample audio with your own short introduction if possible.
5. Test the planner: add a task, mark it completed, delete it, then refresh the page to confirm local storage works.
6. Test the contact form with empty fields, an invalid email, letters in the phone field and valid details.
7. Check the website on both desktop and mobile screen sizes.

IMPORTANT LIMITATIONS
- The planner stores tasks in the current browser using localStorage. It is not a shared online account.
- The contact form validates fields in the browser but does not send messages. A backend or form service is required for real message delivery.
- The sample audio and Google Fonts need an internet connection.
- The project examples are sample portfolio entries; do not claim they are completed personal projects unless you have built them.

GITHUB PAGES
1. Create a GitHub repository for this project.
2. Upload all files and folders, keeping the same folder structure.
3. In repository Settings, open Pages.
4. Select deployment from the main branch and the root folder.
5. Save and wait for GitHub Pages to publish your site.
6. Submit both the published website URL and repository URL as requested by your lecturer.
